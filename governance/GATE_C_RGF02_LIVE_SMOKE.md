# Gate C — smoke vivo RGF Anexo 02

Antes da primeira carga SP645 do Anexo 02, o contrato será validado ao vivo em três municípios.

O smoke:

1. consulta três municípios;
2. preserva a taxonomia longa oficial;
3. aplica o normalizador `pipeline.normalize.rgf02`;
4. exige ausência de conflitos;
5. exige ao menos uma variável canônica observada;
6. produz artifact com bruto, longo, normalizado e manifesto.

A carga estadual continua manual até o smoke ser aprovado.
