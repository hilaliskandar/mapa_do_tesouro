# Gate C — RGF Anexo 02 estadual preparado

O coletor estadual do RGF Anexo 02 está preparado, mas o workflow é exclusivamente manual.

## Regra

A taxonomia oficial é preservada em formato longo:

- ano;
- código IBGE;
- município;
- código de conta;
- rótulo da conta;
- coluna;
- valor;
- população;
- URL da consulta;
- fonte.

Ausências não são inferidas nem transformadas em zero.

## Sequenciamento

O Anexo 02 não deve ser disparado enquanto a primeira carga estadual RGF Anexos 01/05 estiver em execução.

O snapshot CAPAG 2025 já cobre 645/645 municípios para Dívida Consolidada, RCL e Indicador 1, mas não substitui a taxonomia analítica completa do Anexo 02.
