# Serie historica DCA e API v2

A base canonica FINBRA DCA cobre 2013 a 2025 para o conjunto estadual de 645 municipios. A construcao privada da API v2 examinada expoe dados 2021 a 2025. Isso evidencia uma diferenca entre base existente e janela exportada, nao ausencia da base historica. O periodo 2013 a 2020 nao demanda nova coleta, e sim estudo do exportador e contrato da API, mantendo manifestos, cobertura, proveniencia e criterios de comparabilidade. Nao combinar snapshots de versoes distintas. Nenhuma implantacao autorizada.
