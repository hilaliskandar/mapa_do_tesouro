# Finanças Municipais SP v0.1.1

Patch release sobre o baseline v0.1.0.

## Alteração

- barra de navegação por abas mantida em uma única linha;
- rolagem horizontal discreta quando a largura disponível não comporta todas as abas;
- rótulos das abas não quebram internamente;
- teste automatizado de contrato para a responsividade da navegação.

## Escopo

Não altera:

- dados;
- indicadores;
- fórmulas;
- metodologia;
- catálogo;
- tipologias;
- pares;
- cartografia;
- regras de ausência;
- hashes das fontes de dados do baseline v0.1.0.

## Baseline de dados

Permanece o baseline v0.1.0:

- 30 municípios;
- 2013–2025;
- 75 objetos documentados;
- regra territorial `strict_complete`;
- 29.250 observações após derivados;
- 870 pares dirigidos;
- 30 geometrias municipais.

Esta versão existe apenas para identificar formalmente o acabamento visual que será submetido ao preview final e, se aprovado, à produção.
